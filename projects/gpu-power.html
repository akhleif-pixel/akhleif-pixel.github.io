GPU power side channels

Testing whether the power a graphics card draws gives away what it is computing.

When
Jun 2026 – present
Where
Kose Research Group, University of Rochester
My role
Undergraduate Researcher, Hardware Security
  • Python
  • PyTorch
  • NVIDIA NVML
  • Hardware security

Overview

A graphics card reports how much power it is drawing. That number looks harmless, but if different computations leave different power patterns, anyone who can read it may be able to tell what the card is working on. This project tests whether that is true.

What I did

  • Built Python tools with PyTorch and NVIDIA NVML that log GPU power draw while the card runs controlled workloads.
  • Ran five kinds of workload, from matrix multiplication to neural networks, and compared their power traces.

Results and status

  • The five workloads leave distinct power signatures.
  • The power telemetry updates at about 21 Hz, not the 50 Hz requested, which limits how much detail it can leak.
